## 機能概要

チャンクのテキストをEmbeddingモデル（multilingual-e5-large）でベクトル化する。生成されたベクトルはChromaDBに格納され、RAG検索に使用される。

## 振る舞い

### 基本動作

チャンクのテキストを受け取り、ベクトル（数値の配列）を返す。

- モデルはmultilingual-e5-large（ローカル実行）
- 入力テキストは512トークン以内（chunk-splitterが保証）
- バッチ処理に対応する（複数チャンクをまとめてベクトル化）

### 具体例

入力:
```
TypeScriptのジェネリクスは型パラメータを使って
再利用可能な型安全なコードを書く仕組みです。
```

出力: 1024次元の浮動小数点数の配列（multilingual-e5-largeの出力次元）

## 技術判断

- multilingual-e5-largeを採用する理由: 多言語対応（日本語に強い）、ローカル実行可能、Embeddingベンチマークでトップクラスの性能。コストゼロで何回でも実行可能
- モデルファイルはHugging Faceからダウンロードされ、ローカルにキャッシュされる（Docker環境ではボリュームマウントで永続化）

## 境界条件

- 空テキスト → ゼロベクトルを返す、またはエラーとする
- モデルファイルが未ダウンロード → 初回実行時に自動ダウンロードされる
- 512トークンを超える入力 → chunk-splitterが防ぐ前提だが、超えた場合はモデルが先頭512トークンのみ処理する

## スコープ外

- Embeddingモデルの選定・変更（ADR-003でモデル変更時の影響を記載済み）
- ベクトルの次元削減や正規化の最適化
- GPU/CPU実行の切り替え最適化

## 受け入れ基準

- [ ] チャンクテキストからベクトルが生成される
- [ ] 出力ベクトルの次元数がmultilingual-e5-largeの仕様（1024次元）と一致する
- [ ] 複数チャンクのバッチ処理ができる
- [ ] モデルがローカルで実行される
