## 修正箇所: 新規作成ダイアログ（GenerateRoadmapDialog）

### 変更理由

バックエンドに `GET /roadmaps/topics`（トピック候補一覧）と `POST /roadmaps/topics`（自由入力登録）のAPIが追加された。ロードマップ生成ダイアログは「テキスト入力のみ」から「候補リストから選択 + 自由入力の併用」に変更する。

---

### 追加API依存

#### `GET /roadmaps/topics`

トピック候補一覧を返す。3つのソースを統合し、ノート数降順でソート済み。

```typescript
// レスポンス
{
  candidates: Array<{
    name: string         // トピック名（例: "TypeScript"）
    source: "preset" | "note" | "manual"  // 候補の由来
    note_count: number   // 関連ノート件数
  }>
}
```

#### `POST /roadmaps/topics`

自由入力トピックを登録する。既に同名トピックがあれば既存を返す（冪等）。

```typescript
// リクエスト
{ name: string }

// レスポンス（201）
{ name: string, source: "preset" | "note" | "manual", note_count: number }
```

- 空文字・空白のみ → 422

### UX意図

- **「何を入力すればいいかわからない」問題を解消**: プリセット候補がリストされるので、初めてのユーザーでも迷わない。プリセットは「おすすめトピック」として機能する
- **ノート数が学習状況のヒントになる**: `note_count` が多い候補は「既に学習中のトピック」。上にソートされるので自然に目に入り、「このトピックのロードマップを作ろう」という判断材料になる
- **ソースBadgeで出所がわかる**: `preset`=プリセット（システム推奨）、`note`=ノート由来（自分のノートから自動抽出）、`manual`=手動登録（過去に自分で入力したもの）。Badgeの色は3種類で控えめに区別
- **自由入力は「または」セパレータの下**: リストにないトピックも入力できることを明示。「追加」ボタンで `POST /roadmaps/topics` を呼び、リストに追加されてから選択状態になる
- **選択→生成の2ステップ**: リストの行をクリックすると「選択中: {topic}」が表示され、「ロードマップを生成」ボタンが有効化。誤クリック防止

### 修正後のコンポーネント構成

#### トピック候補リスト（TopicCandidateList）

ダイアログ内に表示するスクロール可能なリスト。

| 要素 | 仕様 |
|:---|:---|
| 各行: トピック名 | `name`（font-medium） |
| 各行: ソースBadge | `source` に応じたBadge（outline variant, small） |
| | `"preset"` → 「プリセット」（blue系） |
| | `"note"` → 「ノート」（green系） |
| | `"manual"` → 「手動」（gray系） |
| 各行: ノート数 | `note_count` + 「ノート」（text-xs, muted-foreground、右寄せ） |
| 選択状態 | クリックで行がprimary背景にハイライト |
| スクロール | ScrollArea、最大高さ200px程度 |

#### 自由入力セクション

| 要素 | 仕様 |
|:---|:---|
| セパレータ | 「── または ──」（Separator + テキスト、muted-foreground） |
| 入力欄 | Input（placeholder: 「トピック名を入力」） |
| 追加ボタン | 「追加」（secondary, small）、入力が空ならdisabled |
| 追加時の動作 | `POST /roadmaps/topics` → 成功したらリストに追加 & 選択状態にする |
| エラー | 422 → 入力欄の下に「トピック名を入力してください」（destructiveカラー） |

#### 選択表示 + 生成ボタン

| 要素 | 仕様 |
|:---|:---|
| 選択中表示 | 「選択中: {topic名}」（text-sm, muted-foreground） |
| 未選択時 | 「トピックを選択してください」（text-sm, muted-foreground） |
| 生成ボタン | 「ロードマップを生成」（primary）、未選択時はdisabled |
| 生成時の動作 | 選択中のtopic名で `POST /roadmaps/generate` |
