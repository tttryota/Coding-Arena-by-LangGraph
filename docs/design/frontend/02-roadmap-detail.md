# ロードマップ詳細 — デザインプロンプト

## 前提

- デザインシステム: `00-design-system.md` に従う
- スコア表示パターン: `01-roadmap-list.md` で確立したスコアBadge + Progressバーを再利用
- この画面はクイズセッションへのエントリーポイント

## 画面概要

- **ルート**: `/roadmaps/:roadmapId`
- **目的**: ロードマップのツリー構造（大枠→中枠→具体）を表示し、各項目の理解度を可視化する。具体項目からクイズセッションを開始できる
- **ユーザーストーリー**: ユーザーがロードマップの全体像を把握し、学習したい具体項目を選んでクイズに挑戦する

### UX設計のポイント

- **階層のビジュアル表現**: 大枠→中枠→具体の3段をインデント＋左の縦線で表現する。ファイルツリーと同じパターンなので、開発者は操作を学ぶ必要がない
- **大枠はデフォルト展開、中枠はデフォルト折畳**: 最初に見える情報は大枠の一覧とそのスコア。中枠は興味のあるものだけ開くことで、情報量をコントロールできる。全展開すると数十〜百の項目が並ぶ可能性があるため
- **具体項目は横一行に情報を凝縮**: タイトル、1行の説明(truncated)、スコアBadge、最終クイズ日時、「クイズ開始」ボタンが一行に並ぶ。スキャン性を重視し、縦方向に目を動かすだけで「どこが弱いか」が色でわかる
- **スコアの低い項目が自然に目立つ**: ローズ（不十分）は暗い背景の中で目を引く。意識的に「ここをやろう」と思わなくても、弱点が視覚的に浮かび上がる
- **「クイズ開始」は具体項目にのみ**: 大枠・中枠はまとめテスト（将来対応）用。現状のメイン体験は具体項目のクイズなので、ボタンは具体レベルにだけ表示して迷いをなくす
- **進行中セッションの再開は割り込みではなく確認**: 「クイズ開始」を押したときにin_progressのセッションがあれば、ダイアログで「再開しますか？」と聞く。自動再開にしないのは、ユーザーが「前回の途中から再開」と「最初からやり直し」を選べるようにするため
- **CRUD操作は控えめに**: 項目の追加・移動・削除はオーバーフローメニュー（⋮）に隠す。主要動線（スコア確認→クイズ開始）の邪魔をしない

## API依存

### `GET /roadmaps/{roadmap_id}`

ロードマップの全ツリーを取得する。

```typescript
// レスポンス
{
  roadmap_id: string
  topic: string
  overall_score: number  // 0-100
  items: RoadmapTreeNode[]
}

type RoadmapTreeNode = {
  id: string               // UUID
  title: string
  description: string
  level: "major" | "middle" | "detail"
  score: number            // detail: DB値、middle/major: 子の平均(floor)
  order: number            // 0-based、兄弟内の表示順
  children: RoadmapTreeNode[]  // detailでは空配列
  last_quiz_at: string | null  // ISO 8601、detailのみ
}
```

### `POST /sessions`

クイズセッションを開始する。

```typescript
// リクエスト
{ roadmap_item_id: string }

// レスポンス（201 Created）
{
  session_id: string
  resume_required: boolean      // trueの場合はin_progressセッションあり
  resume_session_id: string | null  // resume_required=trueのとき既存セッションID
}
```

### `POST /roadmaps/{roadmap_id}/items`

項目を追加する。

```typescript
// リクエスト
{
  parent_id: string | null  // nullなら大枠に追加
  title: string
  description: string
  order?: number
}

// レスポンス（201）
{ created_item: RoadmapItemDTO }
```

### `PUT /roadmaps/{roadmap_id}/items/{item_id}/move`

項目を移動する。

```typescript
// リクエスト
{
  target_parent_id: string | null
  target_order: number
}

// レスポンス
{ moved_item: RoadmapItemDTO }
```

### `DELETE /roadmaps/{roadmap_id}/items/{item_id}`

項目とその子孫を削除する。

```typescript
// レスポンス
{
  deleted_item_ids: string[]
  deleted_count: number
}
```

## コンポーネント構成

### ページヘッダー

| 要素 | 内容 |
|:---|:---|
| パンくず | `ロードマップ` > `{topic}` |
| タイトル | `{topic}`（text-xl, font-semibold） |
| 全体スコア | `overall_score` のスコア表示（数値 + Badge + Progress） |

### ツリービュー（RoadmapTree）

再帰的なツリーコンポーネント。各レベルで異なる表示密度を持つ。

#### 大枠ノード（MajorNode）

Collapsibleで展開/折畳可能。

| 要素 | 表示内容 |
|:---|:---|
| 展開アイコン | ChevronRight（折畳時）/ ChevronDown（展開時） |
| タイトル | `title`（text-lg, font-medium） |
| スコア | 数値 + Badge（カラー4段階） |
| 背景 | 微妙なborder-bottom で区切り |
| インデント | なし（ルートレベル） |

#### 中枠ノード（MiddleNode）

Collapsibleで展開/折畳可能。

| 要素 | 表示内容 |
|:---|:---|
| 展開アイコン | ChevronRight / ChevronDown |
| タイトル | `title`（text-base, font-medium） |
| スコア | 数値 + Badge |
| インデント | pl-6（大枠から1段） |

#### 具体ノード（DetailNode）

リーフ要素。クイズ開始のアクションを持つ。

| 要素 | 表示内容 |
|:---|:---|
| タイトル | `title`（text-sm） |
| 説明 | `description`（text-xs, muted-foreground, 1行に切り詰め） |
| スコア | 数値 + Badge |
| 最終クイズ | `last_quiz_at`の相対日時表示（nullなら「—」） |
| アクション | 「クイズ開始」ボタン（primary, small） |
| オーバーフローメニュー | DropdownMenu（移動 / 削除） |
| インデント | pl-12（大枠から2段） |

### セッション再開確認ダイアログ（ResumeSessionDialog）

`POST /sessions` のレスポンスで `resume_required=true` の場合に表示。

| 要素 | 内容 |
|:---|:---|
| タイトル | 「進行中のセッションがあります」 |
| 本文 | 「この項目には進行中のクイズセッションがあります。再開しますか？」 |
| 再開ボタン | 「再開する」（primary） → `/sessions/{resume_session_id}` へ遷移 |
| キャンセルボタン | 「キャンセル」（secondary） |

### 項目追加ダイアログ（AddItemDialog）

| 要素 | 内容 |
|:---|:---|
| タイトル | 「項目を追加」 |
| 入力: タイトル | Input（必須） |
| 入力: 説明 | Textarea（必須） |
| 追加先 | 選択した親ノードのタイトルを表示（読み取り専用） |
| 追加ボタン | 「追加」（primary） |

### 削除確認ダイアログ

| 要素 | 内容 |
|:---|:---|
| タイトル | 「項目を削除」 |
| 本文 | 「{title}を削除しますか？子項目も全て削除されます。」 |
| 削除ボタン | 「削除する」（destructive） |
| キャンセルボタン | 「キャンセル」（secondary） |

## インタラクション

| 操作 | 結果 |
|:---|:---|
| 大枠/中枠のクリック | 展開/折畳のトグル |
| 具体項目の「クイズ開始」ボタン | `POST /sessions` を呼び出し |
| → `resume_required=false` | `/sessions/{session_id}` へ遷移 |
| → `resume_required=true` | ResumeSessionDialog を表示 |
| オーバーフローメニュー > 削除 | 削除確認ダイアログ → `DELETE` API |
| オーバーフローメニュー > 移動 | 移動ダイアログ（移動先の親と順序を選択） |
| 「項目を追加」 | 選択した親ノードに子を追加 |

## 状態管理

### TanStack Query

| フック | クエリキー | 用途 |
|:---|:---|:---|
| `useRoadmap(roadmapId)` | `["roadmap", roadmapId]` | ツリーデータ取得 |
| `useStartSession()` | — | mutation: セッション開始 |
| `useAddItem(roadmapId)` | — | mutation: 項目追加（成功時にroadmapキーを無効化） |
| `useMoveItem(roadmapId)` | — | mutation: 項目移動 |
| `useDeleteItem(roadmapId)` | — | mutation: 項目削除 |

### Zustand

| store | 用途 |
|:---|:---|
| `useTreeState` | 展開/折畳状態の管理（`expandedIds: Set<string>`）。ページ遷移後も展開状態を維持 |

## 画面状態

| 状態 | 表示 |
|:---|:---|
| ローディング | ヘッダーSkeleton + ツリー行Skeleton（5行程度） |
| 表示 | ツリービュー（大枠はデフォルト展開、中枠はデフォルト折畳） |
| 空状態（項目0件） | 「まだ項目がありません」+「項目を追加」ボタン |
| エラー（404） | 「ロードマップが見つかりません」+ ロードマップ一覧へのリンク |
| エラー（その他） | Toast通知 |
