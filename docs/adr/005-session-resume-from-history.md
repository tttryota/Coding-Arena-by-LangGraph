# ADR-005: セッション再開はQuizAnswer履歴から復元する

**ステータス:** 承認
**日付:** 2026-05-18

## コンテキスト

クイズセッションの中断・再開を実現するにあたり、LangGraphのセッション状態をどのように永続化・復元するかを決定する必要がある。

## 決定

LangGraphのチェックポイント永続化は使わず、QuizAnswerの履歴からセッションを復元する。再開時はQuizAnswerに記録された問題文・回答・score・feedbackをLLMに渡し、新しいLangGraphセッションとして続行する。

## 根拠

- QuizAnswerにセッションの全問答が既に記録されている（問題文、回答、score、feedback）。チェックポイントと事実上同じ情報を持つ
- LangGraphのチェックポイント永続化は追加のインフラ（永続化バックエンド）やLangGraph固有のシリアライズ/デシリアライズを必要とし、複雑さが増す
- QuizAnswer履歴からの復元であれば、LangGraphへの依存を減らせる。将来LangGraph以外のワークフローエンジンに変更する場合にも影響が小さい
- LLMは過去の問答履歴を受け取れば文脈を理解して続行できる。チェックポイントと比べて品質の劣化は最小限

## 却下した選択肢

- **LangGraphのチェックポイント永続化**: 機能としては存在するが、追加の永続化バックエンドが必要になり、LangGraphへの依存が強まる。QuizAnswerで代替可能なため不要
