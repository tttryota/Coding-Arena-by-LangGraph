## 観点
- 仕様書の UX 要件と状態遷移が一致しているか
- ローディング、空データ、エラー状態の扱いが仕様と矛盾していないか

- API キャッシュ戦略や mutation 後の挙動に、仕様との不整合がないか

## severity の判定基準
- critical: 正常系導線が成立しない、致命的な状態遷移バグ
- major: 仕様書の動作要件との明確な不一致
- minor: UX 意図からの軽微な逸脱
