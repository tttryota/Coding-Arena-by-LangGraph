# ADR-003: チャンクサイズ上限を512トークンとする

**ステータス:** 承認
**日付:** 2026-05-17

## コンテキスト

RAGパイプラインのチャンク分割において、チャンクのサイズ上限を決定する必要がある。チャンクが長すぎるとEmbeddingモデルの入力上限を超え、超過部分がベクトルに反映されず検索精度が低下する。

## 決定

チャンクサイズの上限を512トークンとする。512トークンを超えるチャンクは段落単位で再分割する。

## 根拠

- 採用するEmbeddingモデル（multilingual-e5-large）の最大入力が512トークン
- 512トークン以内であればチャンク全文がベクトルに反映され、検索精度が担保される
- 512トークンは日本語で約250〜400文字。学習ノートの1セクション分として妥当な分量
- 超過した場合、先頭512トークンのみベクトル化され後半の内容では検索にヒットしなくなる

## Embeddingモデル変更時の影響

この上限はEmbeddingモデルの入力上限に依存している。将来モデルを変更する場合（例: BGE-M3は8192トークン対応）、チャンクサイズ上限も見直す必要がある。

| モデル | 最大トークン |
|--------|------------|
| multilingual-e5-large（現行） | 512 |
| BGE-M3 | 8192 |
| OpenAI text-embedding-3-small | 8191 |
