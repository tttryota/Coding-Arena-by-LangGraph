# クイズセッション — デザインプロンプト

## 前提

- デザインシステム: `00-design-system.md` に従う
- スコア表示: `01-roadmap-list.md` で確立したパターンを再利用
- この画面が最も複雑。バックエンドのLangGraphワークフロー（SessionState）に基づくサブ状態遷移を持つ
- ユーザーはロードマップ詳細画面（`02-roadmap-detail.md`）の「クイズ開始」ボタンからこの画面に遷移する

## 画面概要

- **ルート**: `/sessions/:sessionId`
- **目的**: ロードマップの項目について、LLMとの対話的なクイズを通じて理解度を検証する
- **ユーザーストーリー**: ユーザーがLLMからの出題に回答し、フィードバックを受け取る。わからなければ解説を求められる。全問完了後にセッションサマリーを確認する

### UX設計のポイント

- **集中を妨げないレイアウト**: 問題文と回答欄が画面の主役。サイドバーは控えめな幅で、進捗を確認したいときだけ視線を移す。サイドバーを折り畳めばさらに集中できる
- **回答方法は2系統、使い分けは直感的**:
  - **フォーム入力（メイン）**: 「回答する」ボタンで送信。入力→評価の1対1対応。テスト用紙に書いて提出する感覚
  - **チャット入力（補助）**: 画面下部の小さな入力欄。「この問題の意味がわからない」「もう少し詳しく」のような自由な対話。LLMが内容を分類して適切に処理する
- **「解説して」はワンクリック**: チャット欄に「解説してください」と打つ手間を省く専用ボタン。わからないときの心理的ハードルを下げる
- **フィードバックはインライン表示**: 問題文の直下にフィードバックが差し込まれる。ページ遷移やモーダルではなく、同じ文脈の中で結果を確認できる。「問題→回答→フィードバック」が自然に繋がる
- **深掘り通知は穏やかに**: next_action="deepdive"のとき「理解を深めるための追加の問題があります」と表示。プレッシャーではなく、学びの機会として伝える
- **コードエディタは見た目でモードが伝わる**: 背景色が暗くなり、monospaceフォントに切り替わることで、「ここにはコードを書く」と直感的にわかる
- **進捗サイドバーは視覚的なリズム**: ●（完了）◉（回答中）○（未回答）の3状態で、どこまで進んだかが一目でわかる。テスト用紙の問題番号にチェックを入れていく感覚
- **セッション完了は達成感**: 大きなスコア表示と回答一覧で「やり切った」感覚を演出。各回答のフィードバックは▶で展開でき、復習にも使える
- **エラーリカバリは自然**: LLMの503エラー時はToastで通知し、回答ボタンを再有効化するだけ。入力済みの回答テキストは消えず、そのまま再送信できる

## API依存

### `POST /sessions/{session_id}/input`

ユーザー入力を送信する。セッション開始後の全てのやり取りはこのエンドポイントを通る。

```typescript
// リクエスト
{
  user_input: string        // 回答テキストまたはチャットメッセージ（1文字以上）
  input_source: "form" | "chat"  // 入力元
}

// レスポンス（SessionState相当）
{
  session_id: string
  roadmap_item_id: string
  roadmap_item_level: "detail" | "middle" | "major"
  roadmap_item_title: string
  roadmap_item_description: string
  is_resumed: boolean
  confirmation_points: ConfirmationPoint[]
  current_point_index: number
  current_question_text: string
  current_answer_type: "textarea" | "code"
  user_input: string
  input_source: "form" | "chat"
  input_type: "answer" | "question" | "explanation_request"
  next_action: "next" | "deepdive" | "complete"
  answers: QuizAnswerRecord[]
  total_questions_asked: number
}

type ConfirmationPoint = {
  id: string
  content: string
  format: "knowledge" | "knowledge_and_practice"
}

type QuizAnswerRecord = {
  question_number: number
  confirmation_point_id: string
  question_text: string
  answer_type: "textarea" | "code"
  answer_text: string       // ユーザーの回答（raw保存、無加工）
  score: number             // 0-100
  feedback: string          // LLMからのフィードバック
}
```

### `GET /sessions/{session_id}`

現在のセッション状態を取得する。

```typescript
// レスポンス
{
  session_id: string
  session: {
    id: string
    roadmap_item_id: string
    status: "in_progress" | "completed"
    completed_at: string | null
  }
}
```

## サブ状態遷移

この画面はSessionStateの値に応じて表示が切り替わる。ページ遷移は発生しない。

```
セッション開始
  │
  ▼
[出題中] ← current_question_text が存在
  │
  ├── form入力で回答 → POST input(form) → [フィードバック表示]
  │                                         │
  │                                         ├── next_action="next" → [出題中]（次の問題）
  │                                         ├── next_action="deepdive" → [出題中]（深掘り問題）
  │                                         └── next_action="complete" → [セッション完了]
  │
  ├── chat入力 → POST input(chat) → input_typeで分岐
  │                                  ├── "answer" → [フィードバック表示]
  │                                  ├── "question" → [チャット応答表示] → [出題中]
  │                                  └── "explanation_request" → [解説表示] → [出題中]（同一ポイント再出題）
  │
  └── 「解説して」ボタン → POST input(chat, "解説してください") → [解説表示]
```

## コンポーネント構成

### セッションヘッダー

| 要素 | 内容 |
|:---|:---|
| パンくず | `ロードマップ` > `{topic}` > `クイズ` |
| 項目名 | `roadmap_item_title`（text-lg, font-medium） |
| 項目説明 | `roadmap_item_description`（text-sm, muted-foreground、1-2行） |

### メインエリア — 出題中状態（QuestionPhase）

#### 問題文表示

| 要素 | 仕様 |
|:---|:---|
| 問題文 | `current_question_text`（text-base、Card内に表示） |
| 問題番号 | 「問題 {total_questions_asked}」（text-xs, muted-foreground） |

#### 回答入力エリア

`current_answer_type` に応じて入力コンポーネントが切り替わる。

**`"textarea"` の場合（知識確認）:**

| 要素 | 仕様 |
|:---|:---|
| 入力 | Textarea（rows=6、placeholder: 「回答を入力してください」） |
| 回答ボタン | 「回答する」（primary）、入力が空の場合はdisabled |

**`"code"` の場合（知識+実践確認）:**

| 要素 | 仕様 |
|:---|:---|
| 入力 | monospaceフォントのTextarea（rows=10、placeholder: 「コードを入力してください」） |
| | 背景をやや暗く（bg-slate-900）、font-mono |
| 回答ボタン | 「回答する」（primary） |

#### 補助アクション

| ボタン | 仕様 |
|:---|:---|
| 「解説して」 | ghostバリアント、回答入力の横に配置。クリックで `input_source="chat"`, `user_input="解説してください"` を送信 |

#### チャット入力

| 要素 | 仕様 |
|:---|:---|
| 入力 | Input（placeholder: 「質問や解説リクエストを入力...」） |
| 送信 | Enterキーまたは送信アイコンボタン |
| 送信時 | `input_source="chat"` で送信 |

### メインエリア — フィードバック表示状態（FeedbackPhase）

回答後にインラインで表示される。

| 要素 | 仕様 |
|:---|:---|
| スコア | 数値 + カラーBadge（「85 十分」等） |
| フィードバック | `feedback` テキスト（Card内、やや強調された背景） |
| 深掘り通知 | `next_action="deepdive"` の場合: 「理解を深めるための追加の問題があります」（infoカラー） |
| 次へボタン | 「次の問題へ」（primary）。`next_action="complete"` の場合は「結果を見る」 |

### メインエリア — 解説表示状態（ExplanationPhase）

| 要素 | 仕様 |
|:---|:---|
| ラベル | 「解説」（text-sm, muted-foreground） |
| 解説文 | `explanation_text`（Card内、左ボーダーでアクセント） |
| 続行ボタン | 「理解した、続ける」（primary） → 同一確認ポイントで別角度の再出題 |

### メインエリア — チャット応答表示（ChatResponsePhase）

| 要素 | 仕様 |
|:---|:---|
| 応答 | LLMの回答テキスト（吹き出し風、Card内） |
| 表示位置 | チャット入力の上にインライン表示 |
| 動作 | クイズ進行に影響なし。そのまま回答入力を続けられる |

### メインエリア — セッション完了状態（SummaryPhase）

全問完了後（`next_action="complete"` + progress_update完了）に表示。

| 要素 | 仕様 |
|:---|:---|
| 見出し | 「セッション完了」（text-xl） |
| 総合スコア | 大きな数値表示 + カラーBadge + Progressバー |
| 回答一覧 | ScrollArea内のリスト。各エントリ: |
| | 問題番号、問題文（truncated）、スコアBadge、フィードバック（展開可能） |
| 戻るボタン | 「ロードマップに戻る」（primary） → `/roadmaps/{roadmapId}` |

### セッション進捗サイドバー（SessionProgress）

右サイドバーに常時表示。

| 要素 | 仕様 |
|:---|:---|
| タイトル | 「進捗」（text-sm, font-medium） |
| 問題リスト | 縦方向のステッパー表示 |
| 回答済み | 塗りつぶし丸 + 問題番号 + スコアBadge |
| 回答中 | アニメーション付き丸 + 問題番号 + 「回答中...」 |
| 未回答 | 空丸 + 問題番号 |
| 総問題数 | 「{answered} / 約20問」（text-xs, muted-foreground） |
| 20問収束表示 | total_questions_asked >= 18 のとき「まもなく完了します」 |

## インタラクション

| 操作 | 結果 |
|:---|:---|
| テキスト/コード入力 + 「回答する」クリック | `POST input(form)` → フィードバック表示 |
| チャット入力 + Enter | `POST input(chat)` → input_typeに応じた表示 |
| 「解説して」ボタン | `POST input(chat, "解説してください")` → 解説表示 |
| フィードバック画面で「次の問題へ」 | 次の問題を表示（レスポンスの `current_question_text` を使用） |
| フィードバック画面で「結果を見る」 | セッション完了画面を表示 |
| 解説画面で「理解した、続ける」 | 同一確認ポイントの別角度問題を表示 |
| サマリー画面で「ロードマップに戻る」 | `/roadmaps/{roadmapId}` へ遷移 |
| API 503エラー（一過性LLMエラー） | Toast「接続エラーが発生しました。もう一度お試しください」+ 回答ボタンを再有効化 |

## 状態管理

### TanStack Query

| フック | クエリキー | 用途 |
|:---|:---|:---|
| `useSession(sessionId)` | `["session", sessionId]` | セッション情報取得（初回ロード用） |

### Zustand

| store | 用途 |
|:---|:---|
| `useQuizSessionStore` | セッション画面のUI状態管理 |

```typescript
// store構造
{
  // 現在のフェーズ
  phase: "question" | "feedback" | "explanation" | "chat_response" | "summary"

  // 最新のSessionStateレスポンス
  sessionState: SessionState | null

  // チャット履歴（チャット応答の蓄積用）
  chatMessages: Array<{ role: "user" | "assistant", content: string }>

  // 入力中のテキスト
  answerDraft: string
  chatDraft: string

  // 送信中フラグ
  isSubmitting: boolean
}
```

## 画面状態

| 状態 | 表示 |
|:---|:---|
| ローディング（初回） | Skeletonで問題文エリア + サイドバーをプレースホルダー表示 |
| 出題中 | 問題文 + 回答入力エリア |
| 送信中 | 回答ボタンにスピナー + disabled、入力エリアもdisabled |
| フィードバック表示 | スコア + フィードバック + 次へボタン |
| 解説表示 | 解説テキスト + 続行ボタン |
| チャット応答 | 吹き出し表示（出題中状態を維持） |
| セッション完了 | サマリー全体表示 |
| エラー（503） | Toast通知、操作を再試行可能 |
| エラー（セッション不存在） | 「セッションが見つかりません」+ ロードマップへのリンク |
