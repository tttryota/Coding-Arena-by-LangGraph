# ロードマップ一覧 — デザインプロンプト

## 前提

- デザインシステム: `00-design-system.md` に従う
- この画面はアプリで最初に実装するデータ表示画面。カードグリッドとスコア表示のパターンをここで確立する

## 画面概要

- **ルート**: `/roadmaps`
- **目的**: 全ロードマップの一覧表示と、新規ロードマップの生成
- **ユーザーストーリー**: ユーザーが学習したいトピックのロードマップを選んで詳細画面に進む。まだロードマップがなければ新規に生成する

---

## ビジュアルイメージ & UX意図

### ページの見た目

画面を開くと、暗い背景の上に等間隔で並んだカードが目に入る。各カードは1つの学習トピック（例: "TypeScript", "React設計"）を表し、カード上部にトピック名、中央にスコアのProgressバーとカラーBadge、下部に「大枠 3 / 中枠 12 / 具体 45」のような項目数サマリーと最終活動日が見える。

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  ロードマップ                              [+ 新規作成]      │
│                                                             │
│  ┌─────────────────┐  ┌─────────────────┐  ┌────────────┐  │
│  │ TypeScript       │  │ React設計       │  │ Python基礎  │  │
│  │                  │  │                  │  │             │  │
│  │ ████████░░ 72    │  │ ████░░░░░░ 45    │  │ █████████░ 90│  │
│  │ [部分的]         │  │ [不十分]         │  │ [十分]      │  │
│  │                  │  │                  │  │             │  │
│  │ 大枠3/中枠12/具45│  │ 大枠2/中枠8/具30 │  │ 大枠2/中5/具│  │
│  │ 最終: 2時間前    │  │ 最終: 3日前      │  │ 最終: 昨日  │  │
│  └─────────────────┘  └─────────────────┘  └────────────┘  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

スコアが低いカード（ローズ系）は「ここをやらなきゃ」と自然に目に入り、高いカード（エメラルド系）は達成感を与える。ただしランキングや比較のような序列付けはしない（並び順は作成順で固定）。

### UX設計のポイント

- **カードは大きめに**: 情報を詰め込むのではなく、1カードにトピック名・スコア・規模感の3情報に絞る。詳細はクリック後のツリービューで確認する
- **カード全体がクリッカブル**: 「どこをクリックすればいいの？」という迷いを排除。ホバーで微かに明るくなるフィードバック
- **新規作成は右上に控えめに配置**: メインの関心は既存ロードマップの閲覧。新規作成は頻度が低いのでページヘッダーの右端にテキスト+アイコンのボタンで配置
- **生成はダイアログ内で完結**: LLMによるロードマップ生成は数十秒かかる。ページ遷移せずダイアログ内でスピナーを表示し、完了したら自動で詳細画面に飛ぶ。待ち時間のストレスを閉じた空間に封じ込める
- **空状態は行動を促す**: ロードマップが1つもないときは、カードグリッドの代わりに画面中央にMapアイコンと「ロードマップがまだありません」のメッセージ、そして「新規作成」ボタンを表示。次のアクションが明確

## API依存

### `GET /roadmaps`

ロードマップ一覧を取得する。

```typescript
// レスポンス
{
  items: Array<{
    roadmap_id: string       // UUID
    topic: string            // トピック名（例: "TypeScript"）
    overall_score: number    // 0-100（全大枠の平均、floor）
  }>,
  total_count: number
}
```

注: 一覧 API はツリー構造を含まない。項目数サマリーや最終活動日は詳細 API (`GET /roadmaps/:id`) から取得する。

### `POST /roadmaps/generate`

新規ロードマップの非同期生成を開始する。

```typescript
// リクエスト
{ topic: string }

// レスポンス（202 Accepted）
{ job_id: string, status: "queued" }
```

### `GET /roadmaps/generate/{job_id}`

生成ジョブの状態を取得する（ポーリング用）。

```typescript
// レスポンス
{
  job_id: string
  status: "queued" | "running" | "completed" | "failed"
  roadmap_id?: string       // completed時のみ
  error_code?: string       // failed時のみ
  error_message?: string    // failed時のみ
}
```

## コンポーネント構成

### ページヘッダー

| 要素 | 内容 |
|:---|:---|
| パンくず | `ロードマップ` |
| タイトル | 「ロードマップ」（text-xl, font-semibold） |
| アクション | 「新規作成」ボタン（primary、右寄せ） |

### ロードマップカード（RoadmapCard）

1枚のCardで1つのロードマップを表示する。カード全体がクリッカブル（`/roadmaps/{roadmap_id}` へ遷移）。

| 要素 | 表示内容 | 使用コンポーネント |
|:---|:---|:---|
| トピック名 | `topic`（font-semibold, 15px） | テキスト |
| スコア表示 | `overall_score` の数値（mono, 26px） + カラーBadge + Progressバー | ScoreBadge, Progress |

注: 一覧 API (`GET /roadmaps`) は `roadmap_id`, `topic`, `overall_score` のみ返す。項目数サマリーや最終活動日はツリーデータが必要なため、詳細画面で表示する。

### 新規作成ダイアログ（GenerateRoadmapDialog）

「新規作成」ボタンで開くDialog。候補選択 + 自由入力の併用方式（詳細は `01-roadmap-list-amendment.md` を参照）。

**入力フォーム状態（候補選択式）:**

| 要素 | 仕様 |
|:---|:---|
| 候補リスト | `GET /roadmaps/topics` から取得、ラジオ選択 |
| 自由入力 | `POST /roadmaps/topics` で登録、リストに追加 |
| 生成ボタン | 「ロードマップを生成」（primary、未選択時disabled） |
| キャンセルボタン | 「キャンセル」（ghost） |

**生成中状態:**

| 要素 | 仕様 |
|:---|:---|
| 表示 | スピナー + 「ロードマップを生成中...」メッセージ |
| ポーリング | 3秒間隔で `GET /roadmaps/generate/{job_id}` を確認 |
| 完了時 | ダイアログを閉じて `/roadmaps/{roadmap_id}` へ遷移 |
| 失敗時 | エラーメッセージをダイアログ内に表示 + 「やり直す」ボタン |

## インタラクション

| 操作 | 結果 |
|:---|:---|
| カードをクリック | `/roadmaps/{roadmap_id}` へ遷移 |
| 「新規作成」ボタン | GenerateRoadmapDialog を開く |
| ダイアログで「ロードマップを生成」 | `POST /roadmaps/generate` → ポーリング開始 |
| 生成完了 | ダイアログ閉じる → 新しいロードマップ詳細へ遷移 |

## 状態管理

### TanStack Query

| フック | クエリキー | 用途 |
|:---|:---|:---|
| `useRoadmaps()` | `["roadmaps"]` | ロードマップ一覧取得 |
| `useGenerateRoadmap()` | — | mutation: ロードマップ生成開始 |
| `useGenerationJob(jobId)` | `["roadmapJob", jobId]` | ジョブ状態ポーリング（`refetchInterval: 3000`、status完了で停止） |

### Zustand

この画面ではZustand storeは不要（ダイアログの開閉はローカルstate `useState` で管理）。
