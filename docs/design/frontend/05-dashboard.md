# ダッシュボード — デザインプロンプト

## 前提

- デザインシステム: `00-design-system.md` に従う
- スコア表示: `01-roadmap-list.md` で確立したパターンを再利用
- この画面は最後に実装する。他の全画面（ロードマップ一覧、ロードマップ詳細、クイズセッション、フィードバック一覧）で確立したパターンを集約する概要画面
- ダッシュボードは参照のみ。データの変更操作は含まない

## 画面概要

- **ルート**: `/`（ルート）
- **目的**: 学習状況の全体像を一目で把握し、各画面への導線を提供する
- **ユーザーストーリー**: ユーザーがアプリを開いたとき、学習の全体進捗・最近の活動・未読フィードバックをすぐに確認できる

### UX設計のポイント

- **「今日何をするか決める」画面**: ダッシュボードの目的はデータ表示ではなく**意思決定の補助**。ユーザーは画面を5秒眺めて「スコアが低いTypeScriptをやろう」「未読フィードバックを先に確認しよう」と決められる
- **統計カードは4つに絞る**: 表示できる数値は多いが、認知負荷を考えて4つに絞る。ロードマップ数（規模感）、平均スコア（全体の達成度）、未読FB（要対応）、直近クイズ（学習頻度）。「全体の健康状態」がこの4つでわかる
- **未読FBカードは導線を兼ねる**: 未読が1件以上あるとカードのボーダーがprimaryカラーに光る。クリックするとフィードバック一覧に直行。「気づかせる」のが目的で、強制的な通知ポップアップは使わない
- **ロードマップ概要はコンパクト版**: カード一覧画面（01）と違い、ここでは1行1ロードマップの簡易リスト。topic名とスコアバーだけ。詳細を見たければクリックでロードマップ詳細に飛べる
- **アクティビティはクイズ結果とFBの混合タイムライン**: 2種類のイベントを時系列で混ぜることで「最近何をしたか」が一目でわかる。種類はアイコン（📖クイズ / 💬FB）で区別する
- **全てがリンク**: ダッシュボードは操作の起点。ロードマップ行→ロードマップ詳細、アクティビティ項目→該当画面、「すべて見る」→一覧、未読FB→フィードバック一覧。どこからでも次の画面に移れる
- **完全に空の状態はウェルカム画面**: ロードマップが0件のとき、統計カードを空で並べるのではなく、画面中央に「学習を始めましょう」と大きく表示し、「ロードマップを作成する」ボタンを目立たせる。初回ユーザーが迷わない

## API依存

### `GET /roadmaps`

全ロードマップの一覧を取得する。ダッシュボードでは以下のデータを利用:

```typescript
{
  roadmaps: Array<{
    roadmap_id: string
    topic: string
    overall_score: number
    items: RoadmapTreeNode[]  // detail項目のlast_quiz_atから最近のクイズ数を算出
  }>
}
```

### `GET /ingestion/feedbacks?read_status=unread`

未読フィードバック件数を取得する。

```typescript
{
  items: FeedbackListItem[]
  total_count: number  // この値を未読件数として使用
}
```

## コンポーネント構成

### ページヘッダー

| 要素 | 内容 |
|:---|:---|
| パンくず | `ダッシュボード` |
| タイトル | 「ダッシュボード」（text-xl, font-semibold） |

### 統計カード行（StatCards）

4つのCardを横並びに表示。各カードはコンパクトな数値表示。

#### カード1: ロードマップ数

| 要素 | 仕様 |
|:---|:---|
| ラベル | 「学習中のロードマップ」（text-xs, muted-foreground） |
| 数値 | ロードマップの総数（text-2xl, font-bold） |
| アイコン | Map（muted-foreground、右上配置） |

#### カード2: 平均スコア

| 要素 | 仕様 |
|:---|:---|
| ラベル | 「全体の平均スコア」（text-xs, muted-foreground） |
| 数値 | 全ロードマップの `overall_score` の平均（floor）（text-2xl, font-bold） |
| 色 | スコアカラー4段階に応じた色 |
| アイコン | TrendingUp（muted-foreground） |
| 補足 | スコアが0の場合は「—」表示 |

#### カード3: 未読フィードバック

| 要素 | 仕様 |
|:---|:---|
| ラベル | 「未読フィードバック」（text-xs, muted-foreground） |
| 数値 | `total_count`（text-2xl, font-bold） |
| アイコン | MessageSquare（muted-foreground） |
| クリック | `/feedbacks` へ遷移 |
| 視覚効果 | 未読が1件以上ある場合はカードのborderをprimaryカラーにして目立たせる |

#### カード4: 直近のクイズ

| 要素 | 仕様 |
|:---|:---|
| ラベル | 「直近7日間のクイズ」（text-xs, muted-foreground） |
| 数値 | 全ロードマップのdetail項目で `last_quiz_at` が直近7日以内のものの件数（text-2xl, font-bold） |
| アイコン | BookOpen（muted-foreground） |

### ロードマップ概要（RoadmapSummary）

Card内にコンパクトなロードマップ一覧を表示。

| 要素 | 仕様 |
|:---|:---|
| セクションタイトル | 「ロードマップ」（CardHeader、font-medium） |
| 各行 | `topic` + `overall_score` のスコアBadge + Progressバー |
| クリック | 各行クリックで `/roadmaps/{roadmap_id}` へ遷移 |
| ホバー | accent背景 |
| 「すべて見る」 | CardFooterにリンク「すべて見る →」→ `/roadmaps` へ遷移 |
| 表示件数 | 最大5件（5件以上ある場合に「すべて見る」を表示） |
| 空の場合 | 「ロードマップがありません」+ 「作成する」リンク → `/roadmaps` |

### 最近のアクティビティ（RecentActivity）

Card内にクイズ結果とフィードバックを時系列で表示。

| 要素 | 仕様 |
|:---|:---|
| セクションタイトル | 「最近のアクティビティ」（CardHeader、font-medium） |
| 表示件数 | 最大10件 |
| ソート | 日時降順（最新が上） |

#### アクティビティの種類

**クイズ結果:**

| 要素 | 仕様 |
|:---|:---|
| アイコン | BookOpen（小、muted-foreground） |
| タイトル | ロードマップ項目のタイトル |
| スコア | スコアBadge（カラー4段階） |
| 日時 | 相対日時表示（text-xs, muted-foreground） |

- データソース: 全ロードマップのdetail項目のうち `last_quiz_at` が非nullのものを、`last_quiz_at` 降順で取得

**フィードバック:**

| 要素 | 仕様 |
|:---|:---|
| アイコン | MessageSquare（小、muted-foreground） |
| タイトル | フィードバックのタイトル（truncated） |
| 未読Badge | 未読の場合は「未読」Badge表示 |
| 日時 | `created_at` の相対日時表示（text-xs, muted-foreground） |
| クリック | `/feedbacks` へ遷移 |

- データソース: `GET /ingestion/feedbacks?read_status=unread` の items（最新5件程度）

**空の場合:**
- 「まだアクティビティがありません」

## インタラクション

| 操作 | 結果 |
|:---|:---|
| 未読FBカードをクリック | `/feedbacks` へ遷移 |
| ロードマップ行をクリック | `/roadmaps/{roadmap_id}` へ遷移 |
| 「すべて見る →」クリック | `/roadmaps` へ遷移 |
| アクティビティのFB項目クリック | `/feedbacks` へ遷移 |

## 状態管理

### TanStack Query

| フック | クエリキー | 用途 |
|:---|:---|:---|
| `useRoadmaps()` | `["roadmaps"]` | ロードマップ一覧（01と共有キー） |
| `useUnreadCount()` | `["feedbacks", "unreadCount"]` | 未読件数（04と共有） |
| `useRecentFeedbacks()` | `["feedbacks", { read_status: "unread" }]` | 未読フィードバック取得 |

### Zustand

この画面ではZustand storeは不要（表示のみ、UIステートなし）。

### 派生データの算出

以下のデータはフロントエンドでroadmapsのレスポンスから算出する:

| データ | 算出方法 |
|:---|:---|
| 平均スコア | 全ロードマップの `overall_score` の平均（floor） |
| 直近7日間のクイズ数 | 全detail項目の `last_quiz_at` が `now - 7days` 以降のものをカウント |
| 最近のクイズ結果リスト | 全detail項目を `last_quiz_at` 降順でソート、上位10件 |
