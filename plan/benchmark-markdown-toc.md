## 今回やること
markdown-toc の全 Phase（Phase 1-3）を一括実装する。
ハーネスの初回ベンチマーク実行として、TDD フロー全体の動作確認を兼ねる。
実装先モジュールは backend/benchmark/markdown_toc.py とする。

## 対象テストケース
1. 空文字列を渡すと空の目次が返る
2. 見出しのない本文のみのテキストを渡すと空の目次が返る
3. H1 が1つだけのテキストから、1エントリの目次が生成され、アンカースラッグが正しい
4. H1, H2, H3 が混在するテキストから、レベルに応じた正しいインデント階層の目次が生成される
5. コードブロック内に `# comment` がある場合、その行は見出しとして認識されない
6. 同じテキストの見出しが3つある場合、アンカーが `slug`, `slug-1`, `slug-2` となる
7. min_level=2, max_level=3 を指定すると、H1 と H4 以降が除外される
8. 見出しテキスト内の Markdown 装飾が除去されたプレーンテキストで目次が生成される
9. 日本語を含む見出しのアンカースラッグが正しく生成される
10. H2 と H4 のみで相対インデントが正しく計算される

## やらないこと
- Setext 形式の見出し対応
- HTML 見出しの認識
- ファイル I/O
- 他モジュールとの連携

## 完了条件
- 上記10個のテストが GREEN
- ruff / mypy がパス
- レビュー完了
